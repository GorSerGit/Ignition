# 🖥 Интерфейс

Веб-приложение на **Flask** для работы с АГ-памятью: загрузка БД, визуализация графа, диалог с агентом, ручное добавление фактов, запуск парсинга.

Фронтенд — минималистичный HTML + **vis.js** для графа.

---

## 📂 Состав

| Файл | Назначение |
|------|------------|
| `app.py` | Flask-приложение: маршруты API + рендер `index.html` |
| `templates/index.html` | Одностраничный UI с vis.js-графом и чатом |

---

## 🚀 Запуск

Из **корня** проекта:

```bash
python -m interface.app
```

Сервер поднимется на `http://0.0.0.0:5000`.

Открой в браузере: [http://localhost:5000](http://localhost:5000).

При запуске автоматически загружается БД `data/output/ah_memory.db`, если она существует.

## 🗺 Маршруты API

### 📊 Статистика и граф

| Метод | Маршрут | Что делает |
|-------|---------|-----------|
| `GET` | `/api/stats` | Возвращает `{S, C, P, H, L}` — размеры множеств |
| `GET` | `/api/graph?search=...` | Возвращает узлы и рёбра графа (ограничение 200 узлов, поиск — до 40 соседей) |
| `POST` | `/api/load_db` | Загружает БД по указанному пути |

### 🤖 Агент

| Метод | Маршрут | Что делает |
|-------|---------|-----------|
| `POST` | `/api/ask` | Вопрос → ответ с трассировкой активации и подграфом |
| `POST` | `/api/ignite` | Запуск воспламенения по seed-словам (без генерации) |
| `POST` | `/api/extract_fact` | Извлекает факт из предложения через GigaChat |
| `POST` | `/api/add_fact` | Ручное добавление факта `predicate(subject, object)` |

### 📥 Парсинг

| Метод | Маршрут | Что делает |
|-------|---------|-----------|
| `POST` | `/api/parse` | Запускает фоновый парсинг корпуса |
| `GET` | `/api/parse_status` | Прогресс парсинга |
| `POST` | `/api/load_corpus` | Загружает корпус из папки |

### 🛠 Утилиты

| Метод | Маршрут | Что делает |
|-------|---------|-----------|
| `GET` | `/api/hyperparams` | Возвращает текущие гиперпараметры |
| `POST` | `/api/hyperparams` | Изменяет гиперпараметры на лету |
| `POST` | `/api/validate` | Запускает `val.run_validation()` |
| `GET` | `/api/logs` | Последние 200 строк логов |


## 🎨 Возможности UI

- **Загрузка БД** — указать путь к `ah_memory.db`.
- **Граф** — визуализация через vis.js (узлы: 🔵 символы, 🟢 факты; рёбра: окрашены по типу).
- **Поиск по графу** — ввод слова → подсветка узла и соседей.
- **Диалог с агентом** — чат-форма, выбор модели Ollama.
- **Добавление факта** — форма `predicate / subject / object`.
- **Запуск парсинга** — кнопка + прогресс-бар.
- **Логи** — панель с последними сообщениями.
- **Гиперпараметры** — слайдеры для настройки Ignition Engine.

## 🔧 Конфигурация

Ключевые настройки в `core/config.py`:

```python
INPUT_DIR = "data/input"
OUTPUT_DIR = "data/output"
```

При старте `app.py` пытается автозагрузить БД `data/output/ah_memory.db`.

Порт по умолчанию — `5000`:

```python
app.run(host='0.0.0.0', port=5000, debug=True)
```

Изменить — в конце `app.py`.

## 🔌 Зависимости

- `flask` — веб-сервер
- `flask-cors` — CORS для внешних клиентов
- `networkx` — построение графа
- `vis.js` — визуализация (подключается через CDN в `index.html`)

Установка:

```bash
pip install -r requirements.txt
```

---

## ⚠️ Известные ограничения

- Граф отрисовывается до **200 узлов** — для больших графов используй поиск.
- Парсинг работает в фоновом потоке — веб-сервер не блокируется, но прогресс берётся из глобальной переменной.
- `debug=True` — не использовать в продакшене. Для деплоя — `gunicorn` или `uwsgi`.

---

## 🚀 Деплой в продакшене

```bash
pip install gunicorn
gunicorn -w 4 -b 0.0.0.0:5000 interface.app:app
```

Или через `nginx` как reverse proxy.
