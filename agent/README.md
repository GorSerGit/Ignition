# 🧠 Агент

Ядро проекта — **когнитивный агент на основе ассоциативно-гетерархической памяти**. Здесь реализованы:

- сама структура АГ-памяти `AH = ⟨S, C, P, H, L⟩`;
- хранилище (SQLite);
- **Ignition Engine** — тактовый алгоритм фокуса активации;
- логика восприятия вопроса и генерации ответа.

---

## 📂 Состав

| Файл | Назначение |
|------|------------|
| `models.py` | Dataclasses: `AbstractSymbol` (S), `ConceptSymbol` (C), `Hypernode` (P/H), `Link` (L) |
| `database.py` | SQLite-хранилище: таблицы, индексы, транзакции, авто-миграции, crash recovery |
| `memory.py` | Управление памятью: создание символов через pymorphy3, добавление фактов, связей `IS-A`/`FOLLOW`/`PREDICATE`, защита от циклов |
| `ignition.py` | **Ignition Engine** — тактовое распространение активации по графу (8-шаговый алгоритм Монографии) |
| `ignite_agent.py` | Когнитивный агент: восприятие вопроса → фокус активации → сбор релевантных фактов → контекст для LLM |

## 🏗 Архитектура памяти

Формализм из Монографии (раздел 3):

```
AH = ⟨ S, C, P, H, L ⟩
```

| Компонент | Что это | Где в коде |
|-----------|---------|------------|
| **S** | Абстрактные символы (слова + их парадигмы) | `models.AbstractSymbol`, таблица `symbols` |
| **C** | Гиперсеть общих знаний | `models.ConceptSymbol`, таблица `concepts` |
| **P** | Гиперсеть частных знаний (факты) | `models.Hypernode`, таблица `facts` |
| **H** | Гиперсеть личной истории (эпизоды) | `models.Hypernode`, таблица `episodes` |
| **L** | Ассоциативные связи | `models.Link`, таблица `links` |

Типы связей:
- `PREDICATE` — от гиперсвязи к предикату;
- `SUBJECT`, `OBJECT`, `LOCATION`, `TIME`, `CAUSE`, `INSTRUMENT`, `MATERIAL`, `EFFECT` — роли актантов;
- `IS-A` — иерархия (ациклическая);
- `FOLLOW` — эпизодическая цепочка (ациклическая).

## 🔥 Ignition Engine

Тактовый алгоритм из раздела 8 Монографии (с. 47–48):

1. Вычисление входных импульсов по ассоциативным связям: `z_a = f × w`.
2. Вычисление импульсов по гиперсвязям: `z_h = f × w`.
3. Суммирование: `z = Σz_a + Σz_h`.
4. Обновление возбудимости: `x_{t+1} = g(x_t) = tanh(x_t · (1 − λ) + z)`.
5. Перенос в рабочую память при `x > t`.
6. Обновление весов по правилу Хебба: `w_{t+1} = clip(w_t + η·x_out·x_in, 0, 1)`.
7. Водитель ритма `ν`.
8. Повтор.

### Гиперпараметры

```python
lambda_decay = 0.20       # затухание
threshold_t = 0.40        # порог рабочей памяти
max_ticks = 5             # тактов на запрос
spread_factor = 0.50      # коэффициент распространения
hebbian_eta = 0.02        # скорость обучения Хебба
seed_anchor = 0.70        # якорение seed-узлов
```

Обоснование — в `docs/hyperparams.md`.

## 🚀 Использование

### Как библиотека

```python
from agent.database import AHDatabase
from agent.memory import AHMemory
from agent.ignition import IgnitionEngine

db = AHDatabase("data/output/ah_memory.db")
memory = AHMemory(db)
engine = IgnitionEngine(db)

# Найти seed-узлы
seed_uids = [memory.db.get_symbol_by_canonical("митохондрия").uid]

# Запустить воспламенение
result = engine.query(seed_uids)
print(result["trace_log"])
print(result["working_memory"])
```

### Через веб-интерфейс

Агент доступен по маршруту `POST /api/ask`:

```bash
curl -X POST http://localhost:5000/api/ask \
     -H "Content-Type: application/json" \
     -d '{"question": "Что такое митохондрия?", "model": "llama3.1:8b"}'
```

Ответ содержит:
- `answer` — сгенерированный текст;
- `trace` — потактовый лог активации;
- `facts` — использованные факты;
- `trace_graph` — подграф активированных узлов.

## 🧬 Умный сбор фактов

Функция `collect_facts_smart` в `ignite_agent.py`:

1. **Жёсткий приоритет**: факты, где есть seed-узлы → `score += 100`.
2. **Мягкий приоритет**: факты, где активация `> 0.4` → `score += activation`.
3. Сортировка и отбор топ-N (по умолчанию 30).

Это защищает LLM от информационного шума — в промпт попадают только релевантные факты.

## 🛡 Инварианты

Проверяются в `memory.py`:

- `IS-A` — ориентированный ациклический граф (`_would_create_cycle`).
- `FOLLOW` — тоже ациклический.
- Каждый факт имеет ровно один `PREDICATE`.
- Связи `SUBJECT`/`OBJECT` почти обязательны для каждого факта.

Проверить вручную:

```bash
python -m parsing.val
```
