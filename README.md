# Ignition

# Воспламенение 1.0 — АГ-память

Гибридный когнитивный ИИ-агент на основе **ассоциативно-гетерархической памяти (АГ-памяти)**, реализованный в рамках хакатона «Воспламенение 1.0».

Проект демонстрирует нейросимвольную архитектуру: БЯМ (GigaChat) выступает в роли модуля восприятия, а формализм АГ-памяти — в роли структурированной долговременной памяти и подсистемы логического вывода.

## 🧠 Идея

Современные БЯМ хранят знания в распределённых весах и не дают ни явной структуры предикатов и ролей актантов, ни механизма фокуса активации, ни гиперграфа личной истории. Проект решает эту проблему через формализм **АГ-памяти**:
AH = ⟨ S, C, P, H, L ⟩


где:
- **S** — множество абстрактных символов (первого и второго порядка).
- **C** — гиперсеть общих знаний.
- **P** — гиперсеть частных знаний.
- **H** — гиперсеть личной истории (эпизоды, связанные `FOLLOW`).
- **L** — множество ассоциативных связей и гиперсвязей.

Поверх графа работает **Ignition Engine** — тактовый алгоритм фокуса активации, реализующий 8-шаговую процедуру из Монографии (раздел 8).

Метрики
Проект ориентирован на метрики хакатона:

Метрика	Описание
M1	F1 извлечения ролей актантов
M2	Глубина объяснимого логического вывода
M3	Эффективность сборщика мусора
M4	Сравнение с Vanilla RAG
M5	Устойчивость к классу БЯМ

Гиперпараметры
Пять ключевых гиперпараметров Ignition Engine:

initial_lifetime — время первоначальной жизни элемента.

decay_lambda — функция затухания g.

threshold_t — порог переноса в рабочую память.

hebb_eta — скорость обучения по правилу Хебба h.

pacemaker_nu — частота водителя ритма ν.
